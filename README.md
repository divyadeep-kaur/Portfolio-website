# My Portfolio

A personal portfolio website built to showcase my journey as a Computer Science & AI student, my projects, technical skills, and things I'm currently learning.

## ✦ About

Hi, I'm Divya — a Computer Science & AI student with an interest in software development, artificial intelligence, and web technologies.

This portfolio is a space to document what I'm building, what I'm learning, and how I'm growing as a developer.

## 🚀 Features

- Responsive portfolio design
- Clean and minimal user interface
- Hero / introduction section
- About section
- Projects showcase
- Technical skills section
- Contact section
- Hover effects and CSS transitions
- Responsive layout for different screen sizes

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Transitions
- CSS Animations
- Media Queries
